# Global ONCE政策数据库：内容类型分类版

本版不再把政策机械对应到《海洋碳汇与碳中和》的章节。

分类吸收教材的知识组织方法，将政策内容分为三类：

1. 理论与研究；
2. 负排放工程；
3. 标准、政策与碳交易。

负排放工程进一步区分生态修复增汇工程、渔业碳汇工程、海洋负排放地球工程和其他负排放工程。理论研究主题、工程路径、制度市场主题和MCP/BCP/CCP/SCP碳泵机制分别编码，避免把研究对象、工程技术、文件形式和治理工具混为同一层级。

文件：

- `data.json`：政策数据；
- `classification_codebook.json`：分类代码表；
- `index.html`：政策文本数据库；
- `map.html`：政策地图；
- `sankey.html`：政策流向桑基图。
